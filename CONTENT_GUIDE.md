## 2. Screenshot & Image Specifications

| Property | Standard | Notes |
| :--- | :--- | :--- |
| **Aspect Ratio** | `16:10` (Primary) or `16:9` | Consistent aspect ratio across project cards |
| **Recommended Dimensions** | `1200 x 750 px` or `1600 x 1000 px` | Crisp on high-DPI displays |
| **Formats** | `.webp` (preferred), `.avif`, `.png`, `.jpg` | Optimized file size |
| **Target File Size** | `< 250 KB` per primary image | Use modern image compression |
| **Storage Directory** | `public/images/projects/` | Path in data: `/images/projects/...` |

---

## 3. Preview Video Specifications

| Property | Standard | Notes |
| :--- | :--- | :--- |
| **Format** | MP4 (`H.264`) or WebM | Broad cross-browser playback |
| **Resolution** | `1280 x 720 px` (720p) or `1920 x 1080 px` | Clear interface details |
| **Target Duration** | `10 – 30 seconds` | Focused on UI interactions and page flow |
| **Target File Size** | `< 12 MB` | Ensures smooth mobile buffering |
| **Storage Directory** | `public/videos/projects/` | Path in data: `/videos/projects/...` |

## 4. Copywriting Principles

- **Clear and Professional**: Describe the solution, business category, and technical capabilities accurately.
- **Accurate Categories**:
  - `Static Websites` — Fast, content-focused business sites.
  - `Dynamic Websites` — Corporate sites with integrated CMS or dynamic modules.
  - `E-Commerce` — Online storefronts, product catalogs, and checkout experiences.
  - `Web Applications` — Custom dashboards, client portals, and software tools.
